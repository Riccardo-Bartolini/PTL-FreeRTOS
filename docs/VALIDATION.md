## Coverage boundaries

The policy tests check observed traces and aggregate progress in selected workloads. They do not prove a lossless job queue, wrap-safe time comparisons, all relative deadline boundary cases or all mixed-policy interactions. The production scenario estimates overhead using assumed burner work; it is not an instrumented measurement of supervisor cycles.

The first hosted GitHub Actions run, Linux package/toolchain behavior, and physical boards have not been verified here. See [TIMING_MODEL.md](TIMING_MODEL.md) for retained implementation boundaries.
